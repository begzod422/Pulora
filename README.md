# Pulora
Financial literacy app: dashboard, transactions, budgets, savings goals, calculators. Uzbek (default) / Russian / English. Data lives in your browser's LocalStorage.

Requires Node.js 18+.

    npm install
    npm run dev      # open the printed http://localhost:5173 URL
    npm run build    # production build in dist/

Currency is UZS. "Reset data" restores the demo data; "Download CSV" exports transactions.
